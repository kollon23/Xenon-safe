## Description

Xenon is a Win32 GDI/GDI+ visual and audio effects project featuring 26 sequential stages with custom math-generated sound synthesis.
___________________________________________________

## Warning

This project contains fast flashing lights, screen distortion, and high-frequency audio.

___________________________________________________

## Build Requirements

- C++ Compiler (MSVC / MinGW)
- Linked Libraries: winmm.lib, gdi32.lib, gdiplus.lib, msimg32.lib, user32.lib

Wroten on the C++ language and in VS Code (Visual Studio Code)
